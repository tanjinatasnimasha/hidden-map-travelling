# Hidden Map Travelling

A bilingual travel-agency website for visit and tourist visa application assistance, hotel booking, ticketing, itineraries, group tours, personal guides and custom tours.

## Features
- English and Bangla language options
- Seven service detail dialogs and service filters
- Three illustrated travel inspiration styles
- Custom and group trip planning
- Three-stage trip planner with dates, travellers, duration, services and optional budget
- Inquiry review, email draft, copy and text download
- Shared business contact details authorized by the owner

## Upload to GitHub
1. Extract this ZIP on your computer.
2. Create a separate repository called hidden-map-travelling and choose Private.
3. On an empty repository, click uploading an existing file in Quick setup. Otherwise choose Add file, then Upload files.
4. Upload the extracted files and the assets folder, preserving the folder structure.
5. Use Add Hidden Map Travelling website as the commit message and commit the changes.

Upload the extracted contents, not only the ZIP.

Suggested repository description:
Bilingual website for Hidden Map Travelling, featuring visa assistance, hotel booking, ticketing, itineraries, group tours, personal guides and custom trip planning.

## Files
- index.html: page structure
- styles.css: design and responsive layouts
- model.js: service content, translations, trip validation and inquiry formatting
- app.js: interactive behavior
- assets/: favicon and travel illustrations
- checks.cjs: functional and content checks

No build or package installation is required. Open index.html to view the site locally. Run node checks.cjs to verify the functional and content checks if Node.js is available.

## Updating the hosted website
This export is independent of the existing private Sites deployment. Committing changes to GitHub does not automatically update the current hosted website. A separate deployment is needed.

## Privacy and content
The planner prepares a trip inquiry. It does not send details, store personal information, take payments, issue tickets or reserve hotels automatically. Only the interface language is stored in the browser. Visa application assistance does not guarantee approval.

The three photographs are AI-generated illustrative travel concepts. They are not claimed Hidden Map tour photographs or confirmed packages. Keep this repository private unless public release is explicitly approved.
